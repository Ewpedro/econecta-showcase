## O que é

**Econecta** é o produto principal da startup **TecnoGreen** — um marketplace digital sustentável onde **cada venda gera impacto socioambiental automático e verificável**.

5% de cada venda é destinado automaticamente para financiar projetos reais da TecnoGreen: reflorestamento, conservação de áreas verdes e vacinação de animais.

---

## A Startup — TecnoGreen

A **[TecnoGreen](https://tecnogreen.devfatec-campinas.com.br)** é uma organização de impacto socioambiental que cria produtos digitais para financiar seus próprios projetos de natureza. O modelo é autossustentável: **a receita da tecnologia financia o impacto ambiental**.

### Missão
> *"Conectar empresas e organizações a tecnologias que promovam um ciclo de valor compartilhado onde todos ganham: parceiros, clientes, consumidores e a sociedade."*

### Modelo de Negócio

| Destinação | % por venda | Finalidade |
|---|---|---|
| Vendedor | 85% | Repasse direto via Pix |
| Econecta (infraestrutura) | 7% | Operação e inovação |
| **TecnoGreen (projetos)** | **5%** | **Reflorestamento, conservação, fauna** |
| Cashback Folinhas | 3% | Fidelização do comprador |

### Alinhada com 8 ODS da Agenda 2030 (ONU)

## Funcionalidades

| Módulo | Descrição |
|---|---|
| 🛒 **Marketplace sustentável** | Catálogo, filtros, carrinho, checkout 3 etapas, avaliações |
| 🌿 **Sistema de Folinhas** | Moeda digital com cashback 3%, expiração automática FIFO 12 meses |
| 🎟️ **Plataforma de eventos** | Ingressos, pagamento, check-in QR code, certificados automáticos |
| 💳 **Pagamentos** | Pix e cartão via Mercado Pago SDK v3.8 com webhook HMAC |
| 📊 **Relatório ESG com IA** | Gemini AI · padrões GRI/VSME 2025 · exportação CSV |
| 🔐 **Segurança** | 2FA email · rate limiting · CSRF · bcrypt · 11 vulnerabilidades auditadas |
| ⚙️ **Painéis** | Admin completo · painel do vendedor · painel do comprador |
| 🤖 **Health check com IA** | 80+ testes automatizados com diagnóstico Gemini |
